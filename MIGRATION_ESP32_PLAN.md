# План миграции проекта DavayLoRa

## Этап 1: Подготовка базового кода для Cursor (PlatformIO)
1. Собрать код передатчика (TX) под старую плату (BSFrance) в PlatformIO. **[DONE]**
2. Организовать структуру проекта: разделить код TX и RX по отдельным корневым папкам (например, `DavayLoRa_TX` и `DavayLoRa_RX`), чтобы избежать конфликта компиляторов. **[DONE]**
3. Добавить в рабочую область код приемника (RX). **[DONE]**
4. Адаптировать код RX под стандарт C++ для PlatformIO (объединение `.ino` файлов, переименование в `.cpp`, добавление `<Arduino.h>` и прототипов функций, исправление форматов данных). **[DONE]**
5. Скомпилировать проект RX без ошибок для платы BSFrance. **[DONE]**

## Этап 2: Физическое тестирование и фиксация (Git) **[DONE]**
6. Прошить физические модули (BSFrance / Adafruit) новым скомпилированным кодом TX и RX.
7. Проверить реальную работоспособность связи по LoRa и всех функций (отклик кнопки, светодиоды, логика сна и измерения батареи).
8. Зафиксировать изменения в Git и отправить на GitHub в новую ветку (branch) `Cursor`.

## Этап 3: Переход на новую аппаратную платформу (Heltec ESP32)
9. Создать в Git новую ветку (например, `heltec-port`) на базе ветки `Cursor`.
10. Изменить конфигурацию `platformio.ini` для платы `heltec_wireless_stick_lite`.
11. Адаптировать библиотеки и пины (включая замену AVR-специфичной библиотеки `GyverPower` на встроенные механизмы глубокого сна ESP32) с обязательным пошаговым контролем.
12. Скомпилировать, прошить и протестировать работу проекта на новых модулях Heltec.
### Что было изменено:
- Библиотеки: Удалены LoRa.h и AVR-специфичная GyverPower.h. Добавлены RadioLib.h и esp_sleep.h.
- Пины Heltec V3: Применена новая карта пинов. Vext (управление батареей) на 36, АЦП на 1. Исполнительные пины переведены на безопасные 41 и 42, статус LED на 35. Пины SPI и SX1262 прописаны для V3.
- Радиомодуль (RadioLib): Синтаксис LoRa.* заменен на методы radio.*. Добавлено прерывание setFlag(), функция проверки checkReceive() и двухбайтовый SyncWord. Подстройка частоты (которая была в вашем RX) переведена в мегагерцы: radio.setFrequency(workFrequency / 1000000.0).
- Батарея: Внедрен новый алгоритм поиска "пилы" (sawtooth ripple) напряжения для точного определения наличия аккумулятора, плюс множитель делителя 4.9.
- Глубокий сон: Команды библиотеки GyverPower заменены на нативный esp_deep_sleep_start().
- Статус и батареечный led переведены на GPIO35 - встроенный LED платы
(Кнопочный ЛЕД TX переведён на DigitalWright, Analog - не работал)
- DigitalWrite и AnalogWrite оказалось нельзя смешивать на ESP32
- код откомментирован. Конец Этапа 3.
